# Reimbursement Audit

The reimbursement audit module scans inventory and order history to identify cases where the marketplace owes the seller money. This includes lost or damaged inventory, overcharged fees, and other discrepancies.

---

## What You Will Learn

- How reimbursement opportunities are identified
- How the reimbursement report is structured
- How reimbursement data is analyzed by reason and product
- How the reimbursement charts work

---

## What Can Be Reimbursed

Marketplaces owe sellers money in several situations:

| Scenario | Description |
| ------------------- | ----------------------------------------------------------------- |
| Lost Inventory | FBA warehouse loses a unit of inventory |
| Damaged Inventory | FBA warehouse damages a unit |
| Customer Returns | Item returned but not returned to sellable inventory |
| Fee Overcharges | Amazon charges incorrect fees |
| Weight/Size Errors | Amazon misclassifies an item's weight or dimensions |

---

## Reimbursement Report

The reimbursement page shows:
- **Total potential reimbursement** — Sum of all identified claims
- **By reason chart** — Breakdown of claims by type (lost, damaged, fee errors)
- **By product chart** — Top products with reimbursement opportunities
- **Claims table** — Individual claim details with ASIN, reason, amount, date

---

## Charts

Two charts visualize the reimbursement data:

### Reimbursement by Reason

A pie or bar chart showing how much potential reimbursement falls into each category (lost, damaged, fee overcharge, etc.). This helps sellers prioritize which claims to file first.

### Top Reimbursement by Product

A bar chart showing the products with the highest potential reimbursement amounts. If a single product has significant lost inventory claims, that is worth investigating.

---

## Claims Table

The claims table lists individual reimbursement opportunities:
- ASIN
- Product name
- Reason (lost, damaged, fee, etc.)
- Estimated amount
- Date of issue
- Status (identified, filed, resolved)
- Actions (file claim, view details)

---

## Interview Talking Points

**On identifying reimbursement opportunities:** "The marketplace processes so many transactions that errors are inevitable — lost inventory, incorrect fees, weight misclassifications. The reimbursement audit scans for these automatically. It is a feature that can directly recover money for sellers with minimal effort."
